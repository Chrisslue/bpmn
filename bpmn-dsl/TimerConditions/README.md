# TimerConditions Language

## About

Time expressions for BPMN timer events.

### Built With

- [MontiCore][monticore-website] (version 5.0.2)
- [Joda-Time][joda-time-website]
- [Cron-utils][cron-utils-website]

## Getting Started

### Installation

```bash
mvn clean install
```

## Project Structure

```text
./src
├── main
│   ├── grammars            # Grammar files
│   └── java                # Java files
└── test                    # Test files
```
