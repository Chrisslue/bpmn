# BPMN

This repository contains the MontiCore BPMN language and associated tooling. 
The gradle-project for the BPMN Language can be found under `bpmn-dsl`. 
It is recommended to only open the project under `bpmn/bpmn-dsl` in your IDE, 
not the entire repository.

## Build BPMN-DSL

* Install Gradle 7.5
* Install Java 11
* Build with command `gradle build`
